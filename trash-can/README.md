# trash-can

現在の実行フローで使わなくなったファイルの置き場です。
**削除はせず、ここへ移動して履歴として残します。**
ここにあるファイルは実行・import されません。

| 移動したもの | 移動日 | 理由 |
| --- | --- | --- |
| `__pycache__/` (*.pyc 5件) | 2026-09-12 | Python が実行時に自動生成するキャッシュ。ソースから毎回作り直されるためリポジトリに置く必要がなく、Git 管理対象からも外した（`.gitignore` に追加）。 |

※ `.pyc` は `.gitignore` の対象のため Git には登録されません（ディスク上には残っています）。
  過去のコミット履歴にも残っているため、必要になれば取り出せます。
